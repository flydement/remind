# 小猫工作助手

面向个人与职场办公的结构化日程追踪、智能提醒、番茄专注与周月报生成工具。同时提供 **Web / PWA 在线网页版** 与 **Windows 桌面托盘版**。

- **在线体验（GitHub Pages）**：https://flydement.github.io/remind/

## 核心特性

1. **自然语言极速创建工作项**  
   同时支持**连续自然口语长句**与**空格词令简写**（按 `Enter` 一键入库，按 `Ctrl+Enter` 展开详细配置）：
   - 长句示例：`任务：整理财务月报 截止日期2026年12月31日 从今天开始每天早上10点提醒我一次 #财务 重点 @张三`
   - 简写示例：`周五 15:30 架构评审 #研发 重点` / `月报 8月11号 提前5天通知 #财务`

   | 语义维度 | 支持写法示例 |
   | --- | --- |
   | 标题与前缀 | 直接书写标题，或 `任务：` / `事项：` / `待办：` / `提醒我…` 开头 |
   | 截止日期 | `截止日期2026年12月31日`、`12/31前`、`周五之前`、`明天`、`3天后`、`下周三`、`月底`、`年底` |
   | 提醒起点 | `从今天开始`、`自12月1日起`、`即日起`、`提前5天`、`提前一周`、`从12月1日到12月15日` |
   | 时刻与频次 | `每天早上10点提醒我一次`、`每个工作日 09:30`、`下午三点半`、`明早9点`、`每小时`、`不提醒` |
   | 周期循环 | `每天重复`、`每个工作日重复`、`每周五`、`每月10号`（无截止日时写 `每天…` 自动归为周期例行事项） |
   | 属性标记 | 优先级 `重点` / `一般`（或 `【重点】`）、标签 `#财务`、责任人 `@张三` / `负责人：张三`、`备注：说明内容` |

2. **列表与三栏看板双视图 + 子任务拆解**  
   支持 `待办 / 进行中 / 已完成` 三态流转、置顶、子步骤拆解进度、标签筛选、逾期一键顺延与误删撤销。
3. **内置无漂移番茄专注计时**  
   支持关联具体工作项开启 15–60 分钟专注倒计时，自动统计每日与事项累计专注时长并计入报告。
4. **多模板周报月报与标准 Excel 台账导出**  
   内置 **严谨汇报版 / 精简要点版 / 温和复盘版** 三套文本模板，支持切换历史周期、在线微调正文、复制全文或导出 Markdown（`.md`）；同时支持按标准合并单元格模板一键导出 `.xlsx` 月度工作完成情况及下月计划表（按重点工作 / 一般工作自动归类编号）。
5. **健康节律与会议勿扰**  
   工作时段内智能提醒饮水、起身活动与远眺护眼，支持打卡重置、新增自定义提醒及一键开启 60 分钟会议勿扰。
6. **全局命令面板与七套个性主题**  
   按 `Ctrl+K` 随时呼出全局搜索与命令面板；内置 **严谨商务**、**青竹护眼（豆沙绿）**、**极简冷淡（北欧灰）**、**樱花奶芙（可爱风）**、**元气波普（卡通风）**、**温润纸感**、**深色专注** 共七套主题。

## 键盘快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + K` | 打开全局搜索与快捷命令面板 |
| `N` | 快速聚焦一句话新建输入框 |
| `Enter` / `Ctrl + Enter` | 极速创建事项 / 展开详细配置弹窗 |
| `Alt + 1 ~ 6` | 快速切换六大功能页 |
| `Esc` | 关闭当前弹窗或提醒卡片 |

## 本地开发与构建

```bash
npm install

# 启动网页版开发预览 (http://localhost:5173)
npm run dev

# 运行类型检查与单元测试
npm run typecheck
npm test

# 构建静态网页版 (输出至 dist-web/)
npm run build

# 打包 Windows 免安装桌面版 (输出至 dist/)
npm run pack:win
```
