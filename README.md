# 小猫工作助手

工作提醒应用：一句话创建工作项、自动写周报月报、每天推一句轻松文字、定时提醒喝水走动。

## Windows 直接用

把 `dist/小猫工作助手-windows.zip` 拷到 Windows 电脑，解压后双击 **小猫工作助手.exe**。

也可以直接拷整个文件夹 `dist/小猫工作助手-win32-x64/`，同样双击 `小猫工作助手.exe`。不需要安装。

关掉窗口会缩到托盘，提醒还会继续；要从托盘图标右键选「退出」才真正关闭。

重新打包：

```bash
npm install
npm run pack:win
```

## 开发预览

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。

## 四个功能

1. **工作项**  
   点「新建工作项」，输入 `月报 8月11号 提前5天通知`：生成名为「月报」的事项，截止日期 8 月 11 日，并在 5 天前（8 月 6 日）提醒。创建后仍可改几点通知、提前几天、频次（一次 / 每天 / 工作日 / 每小时）。
2. **周报月报**  
   根据当期工作项自动汇总完成、待办、逾期，生成可复制文本。
3. **语言库**  
   每天固定时间推一句鸡血、脑筋急转弯或笑话。可自己加内容。
4. **健康提醒**  
   定时提醒喝水、站起来走走、看远处。可改间隔和工作时段。

## 以后接到手机

可复用：

- `src/shared/parser.ts` 一句话解析
- `src/shared/scheduler.ts` 提醒判定
- `src/shared/reports.ts` 周报月报
- `src/shared/types.ts` 数据模型

需要按平台替换的只有：系统通知、本地存储、后台保活。
